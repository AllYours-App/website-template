=====================================================
PROCÉDURE TECHNIQUE - DÉVELOPPEUR
Cas spécifique : Vercel + GitHub (hébergement gratuit)
=====================================================

OBJECTIF : Connecter le domaine du client (ex: peintredupont.fr) 
à ton projet hébergé sur Vercel, en passant par GitHub.

-----------------------------------------------------
PHASE 1 : PRÉPARATION DU CODE (GitHub)
-----------------------------------------------------
1) Ton code est déjà sur un dépôt GitHub (public ou privé, Vercel gère les deux).
2) Assure-toi d'avoir un fichier à la racine (ex: index.html) pour que Vercel 
   sache quoi afficher par défaut.
3) Si tu utilises un framework (React, Vue), vérifie que le build fonctionne 
   en local (npm run build).

-----------------------------------------------------
PHASE 2 : IMPORTER LE PROJET SUR VERCEL
-----------------------------------------------------
1) Va sur vercel.com et connecte-toi avec ton compte GitHub.
2) Clique sur "Add New" → "Project".
3) Importe le dépôt GitHub correspondant au site du client.
4) Laisse les paramètres par défaut (Vercel détecte automatiquement le framework).
5) Clique sur "Deploy". 
6) ✅ Ton site est EN LIGNE sur une URL du style : 
   https://mon-projet.vercel.app

👉 Envoie cette URL au client pour qu'il valide le rendu (design, textes) 
   AVANT de toucher au domaine. C'est ta "version de test".

-----------------------------------------------------
PHASE 3 : AJOUTER LE DOMAINE PERSONNALISÉ DANS VERCEL
-----------------------------------------------------
1) Dans ton tableau de bord Vercel, clique sur le projet du client.
2) Va dans l'onglet "Settings" → "Domains".
3) Dans le champ "Enter your domain", tape : peintredupont.fr
4) Clique sur "Add".
5) Vercel te dit : "Invalid configuration" (normal, le DNS ne pointe pas encore).
6) Note bien les instructions que Vercel t'affiche. Elles vont te dire exactement 
   quoi ajouter chez OVH/Gandi. Généralement, c'est :

   - Pour le sous-domaine "www" :
     Type CNAME → Nom : www → Cible : cname.vercel-dns.com

   - Pour le domaine nu "peintredupont.fr" (le @) :
     Type A → Nom : @ → Cible : 76.76.21.21

   ⚠️ Si OVH n'accepte pas de mettre un CNAME sur le @ (ce qui arrive souvent), 
      utilise la solution des enregistrements A ci-dessus. C'est validé par Vercel.

-----------------------------------------------------
PHASE 4 : MODIFIER LA ZONE DNS CHEZ LE REGISTRAR (OVH/Gandi)
-----------------------------------------------------
1) Connecte-toi au compte du client (OVH, Gandi, etc.).
2) Va dans la "Zone DNS" du domaine.
3) Supprime tous les enregistrements "A" et "CNAME" existants (sauf les emails MX 
   si le client a une boîte pro chez OVH, mais pour un premier site, on s'en fiche).
4) Ajoute EXACTEMENT ce que Vercel t'a demandé à l'étape 3 :
   - Enregistrement A : Nom = @ | Cible = 76.76.21.21
   - Enregistrement CNAME : Nom = www | Cible = cname.vercel-dns.com
5) Sauvegarde.

-----------------------------------------------------
PHASE 5 : LAISSER PROPAGER ET VALIDER CHEZ VERCEL
-----------------------------------------------------
1) La propagation DNS peut prendre de 2 minutes à 48h (généralement 15 min).
2) Retourne sur Vercel → Settings → Domains.
3) Clique sur "Refresh" ou "Verify Configuration" à côté du domaine.
4) Quand Vercel voit les bons enregistrements, il passe le statut à "Valid" 
   et active AUTOMATIQUEMENT le HTTPS (certificat SSL Let's Encrypt).
5) ✅ Ton site est officiellement en ligne sur https://peintredupont.fr

-----------------------------------------------------
PHASE 6 : LA PUISSANCE DE GITHUB (Mises à jour)
-----------------------------------------------------
Le gros avantage : pour modifier le site plus tard :
1) Tu modifies un fichier sur ton ordinateur.
2) Tu fais : git add . / git commit -m "modif" / git push origin main
3) Vercel détecte automatiquement le push sur GitHub et redéploie le site 
   en moins de 30 secondes. Zéro manipulation chez OVH ou Vercel à faire.

-----------------------------------------------------
🛑 VÉRIFICATIONS FINALES (avant de rendre au client)
-----------------------------------------------------
- Teste https://peintredupont.fr (le cadenas doit être vert).
- Teste http://peintredupont.fr (ça doit rediriger automatiquement vers https).
- Teste www.peintredupont.fr (ça doit afficher le même site).
- Envoie-toi un message via le formulaire de contact pour vérifier qu'il arrive.

-----------------------------------------------------
🔐 SÉCURITÉ ET RESTITUTION
-----------------------------------------------------
1) Déconnecte-toi du compte du client (OVH/Gandi).
2) Dis-lui : "Votre site est en ligne. Je vous conseille de changer votre mot 
   de passe OVH pour plus de sécurité."
3) Conserve dans tes archives :
   - Le nom du dépôt GitHub.
   - Le lien Vercel du projet.
   - La date de renouvellement du domaine (pour l'alerter dans 11 mois).
