=====================================================
PROCÉDURE TRANSFERT VERCEL (Client -> Développeur)
=====================================================

OBJECTIF : Le client crée son compte Vercel gratuit, et je lui transfère
le projet final depuis mon compte. Le client devient propriétaire.

-----------------------------------------------------
PHASE 1 : CE QUE J'ENVOIE AU CLIENT (par mail)
-----------------------------------------------------
Objet : Création de votre compte Vercel (2 minutes)

Bonjour,

Pour finaliser la mise en ligne, merci de suivre ces 3 étapes :

1) Allez sur https://vercel.com
2) Cliquez sur "Sign Up" et choisissez "Continue with GitHub" 
   (si vous n'avez pas GitHub, choisissez "Continue with Email").
3) Utilisez votre adresse email professionnelle.
4) Vérifiez votre boîte mail pour confirmer l'inscription.

Une fois fait, envoyez-moi simplement l'adresse email que vous avez utilisée.
Je m'occupe du reste !

Merci,
[Mon nom]

-----------------------------------------------------
PHASE 2 : VÉRIFICATION (côté développeur)
-----------------------------------------------------
- Dès que le client m'envoie son email, je vérifie qu'il a bien créé
  son compte (je peux aller sur vercel.com/[son-email] ou juste lui
  demander une confirmation visuelle).
- IMPORTANT : Le client doit avoir confirmé son adresse email
  (le lien reçu dans sa boîte mail). Sans confirmation, le transfert échoue.

-----------------------------------------------------
PHASE 3 : LE TRANSFERT DE PROJET (DU MIEU VERS LE CLIENT)
-----------------------------------------------------
1) Connecte-toi à TON compte Vercel (celui où se trouve le projet fini).
2) Va dans le tableau de bord et clique sur le projet à transférer.
3) Va dans l'onglet "Settings" → onglet "General".
4) Scrolle tout en bas jusqu'à la section "Danger Zone".
5) Clique sur le bouton "Transfer Project".
6) Une fenêtre s'ouvre. Dans le champ, tape l'adresse email du client.
7) Clique sur "Transfer". 
8) Vercel envoie immédiatement un email au client.

-----------------------------------------------------
PHASE 4 : LE CLIENT ACCEPTE LE TRANSFERT
-----------------------------------------------------
- Le client reçoit un email de Vercel avec un bouton "Accept Transfer".
- Il clique dessus.
- Il est redirigé vers Vercel où il voit le projet apparaître dans son tableau de bord.
- ✅ LE TRANSFERT EST TERMINÉ. Le projet n'est plus dans ton compte.

-----------------------------------------------------
PHASE 5 : RECONFIGURATION DU DOMAINE (SI DÉJÀ AJOUTÉ)
-----------------------------------------------------
⚠️ ATTENTION : Les domaines personnalisés ne sont PAS transférés automatiquement.
Si tu avais déjà ajouté le domaine "peintredupont.fr" sur TON compte :

1) Avant de transférer : Supprime le domaine de TON projet Vercel
   (Settings → Domains → Remove).

2) Après le transfert (chez le client) : Le client va dans son tableau de bord,
   clique sur le projet transféré, va dans "Settings" → "Domains", 
   et ajoute "peintredupont.fr".

3) Si les DNS pointent déjà vers Vercel (nameservers ou enregistrements A/CNAME),
   la validation se fait automatiquement en 2 minutes.

4) Si le client n'a pas encore acheté le domaine, il peut le faire chez OVH
   et suivre la procédure de configuration DNS (voir mon autre fichier).

-----------------------------------------------------
PHASE 6 : QUE DEVIENS-TU APRÈS LE TRANSFERT ?
-----------------------------------------------------
- Tu perds l'accès en écriture sur le projet (tu ne peux plus faire de `git push`
  vers ce projet depuis ton compte).
- Mais le client peut t'ajouter comme "Collaborator" sur SON compte Vercel
  (Settings → Members → Add Member) si tu dois continuer à faire des modifs.
- Pour les modifications futures, tu as deux options :
    a) Le client te donne les droits "Admin" sur son projet Vercel.
    b) Tu bosses sur le code, tu fais un `git push` (si le repo GitHub est
       toujours accessible), et c'est le client qui déclenche le déploiement
       (ou toi, si tu es collaborateur).

-----------------------------------------------------
⚠️ PIÈGES À ÉVITER
-----------------------------------------------------
1) N'attends pas le dernier jour pour faire le transfert. Fais-le au moins
   48h avant la date de livraison, au cas où le client traîne pour accepter
   l'email de Vercel.

2) Vérifie que le client a bien CONFIRMÉ son adresse email sur Vercel.
   Sans validation, le transfert est refusé.

3) Si le client utilise "Continue with GitHub", assure-toi que son compte
   GitHub est actif. Si c'est "Continue with Email", vérifie qu'il a
   mis un mot de passe fort.

4) Le transfert est IRRÉVERSIBLE depuis ton côté. Une fois transféré,
   tu ne peux pas le reprendre sans que le client ne te le retransfère.
