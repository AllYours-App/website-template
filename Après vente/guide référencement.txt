================================================================================
        GUIDE COMPLET : RÉFÉRENCEMENT SEO — GITHUB + VERCEL
================================================================================

Ce guide couvre tout ce dont tu as besoin pour bien référencer ton site web
hébergé sur Vercel, avec un dépôt source sur GitHub.

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 1 — PRÉPARER TON DOMAINE
────────────────────────────────────────────────────────────────────────────────

1.1 Utiliser un domaine personnalisé (fortement recommandé)
   - Évite les URLs en *.vercel.app pour le SEO (peu crédibles aux yeux de Google)
   - Achète un domaine sur OVH, Namecheap, Gandi, etc.
   - Dans Vercel > Settings > Domains, ajoute ton domaine perso

1.2 Forcer le HTTPS
   - Vercel active le HTTPS automatiquement via Let's Encrypt
   - Vérifie que toutes les URLs redirigent bien vers https:// (sans www OU avec www, mais pas les deux)

1.3 Choisir une URL canonique
   - Décide : https://monsite.com  OU  https://www.monsite.com
   - Configure une redirection 301 permanente de l'une vers l'autre
   - Dans vercel.json :

     {
       "redirects": [
         {
           "source": "https://www.monsite.com/(.*)",
           "destination": "https://monsite.com/$1",
           "permanent": true
         }
       ]
     }

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 2 — LES FICHIERS ESSENTIELS À AJOUTER DANS TON REPO GITHUB
────────────────────────────────────────────────────────────────────────────────

2.1 robots.txt
   Fichier : /public/robots.txt

   User-agent: *
   Allow: /
   Sitemap: https://monsite.com/sitemap.xml

   → Dis aux moteurs quelles pages crawler et où trouver le sitemap

2.2 sitemap.xml
   Fichier : /public/sitemap.xml

   <?xml version="1.0" encoding="UTF-8"?>
   <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
     <url>
       <loc>https://monsite.com/</loc>
       <lastmod>2025-01-01</lastmod>
       <priority>1.0</priority>
     </url>
     <url>
       <loc>https://monsite.com/a-propos</loc>
       <lastmod>2025-01-01</lastmod>
       <priority>0.8</priority>
     </url>
   </urlset>

   → Liste toutes tes pages importantes. Si tu utilises Next.js ou Astro,
     des librairies comme "next-sitemap" peuvent le générer automatiquement.

2.3 vercel.json (headers SEO)
   Fichier : /vercel.json (à la racine du repo)

   {
     "headers": [
       {
         "source": "/(.*)",
         "headers": [
           { "key": "X-Robots-Tag", "value": "index, follow" },
           { "key": "X-Content-Type-Options", "value": "nosniff" },
           { "key": "X-Frame-Options", "value": "SAMEORIGIN" }
         ]
       }
     ]
   }

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 3 — BALISES HTML INDISPENSABLES (dans chaque page)
────────────────────────────────────────────────────────────────────────────────

Dans le <head> de chaque page :

<!-- Titre de la page (60-70 caractères max) -->
<title>Mon super service | Nom du site</title>

<!-- Description (150-160 caractères max) -->
<meta name="description" content="Description claire de la page, avec mots-clés naturels.">

<!-- URL canonique (évite le contenu dupliqué) -->
<link rel="canonical" href="https://monsite.com/la-page-actuelle" />

<!-- Open Graph (pour les partages sur réseaux sociaux) -->
<meta property="og:title" content="Mon super service" />
<meta property="og:description" content="Description claire de la page." />
<meta property="og:url" content="https://monsite.com/la-page-actuelle" />
<meta property="og:image" content="https://monsite.com/images/og-image.jpg" />
<meta property="og:type" content="website" />

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Mon super service" />
<meta name="twitter:description" content="Description claire de la page." />
<meta name="twitter:image" content="https://monsite.com/images/og-image.jpg" />

<!-- Langue -->
<html lang="fr">

ÉTAPE 4 — PERFORMANCE (Core Web Vitals — critères Google)
────────────────────────────────────────────────────────────────────────────────

Google classe les sites selon 3 métriques clés :

  LCP (Largest Contentful Paint) → Temps de chargement du contenu principal
  FID / INP (Interaction to Next Paint) → Réactivité
  CLS (Cumulative Layout Shift) → Stabilité visuelle

Bonnes pratiques :

4.1 Images
   - Utilise le format WebP ou AVIF
   - Ajoute toujours width + height sur les balises <img>
   - Si Next.js : utilise le composant <Image> (optimisation automatique)
   - Lazy loading : <img loading="lazy" ...>

4.2 Polices
   - Héberge les polices localement si possible
   - Utilise font-display: swap dans ton CSS

4.3 Compression & Cache (vercel.json)
   {
     "headers": [
       {
         "source": "/static/(.*)",
         "headers": [
           { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
         ]
       }
     ]
   }

4.4 Vérifie ta performance
   - https://pagespeed.web.dev → analyse LCP/CLS/INP
   - https://gtmetrix.com
   - Vise un score Lighthouse > 90 sur mobile

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 5 — SOUMETTRE SON SITE À GOOGLE
────────────────────────────────────────────────────────────────────────────────

5.1 Google Search Console
   - Va sur : https://search.google.com/search-console
   - Ajoute ta propriété (type "Domaine" ou "Préfixe d'URL")
   - Vérifie la propriété via un fichier HTML ou une balise meta
     → Exemple avec balise meta :
       <meta name="google-site-verification" content="XXXXX" />
   - Soumets ton sitemap : dans Search Console > Sitemaps > https://monsite.com/sitemap.xml

5.2 Bing Webmaster Tools (optionnel mais utile)
   - https://www.bing.com/webmasters
   - Même démarche que Google

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 6 — CONTENU & STRUCTURE (le vrai SEO long terme)
────────────────────────────────────────────────────────────────────────────────

6.1 Structure des titres
   - 1 seul <h1> par page (titre principal avec le mot-clé cible)
   - Des <h2>, <h3>... pour structurer le contenu

6.2 Mots-clés
   - Identifie les termes cherchés par ta cible (Google, Ubersuggest, SEMrush...)
   - Intègre-les naturellement dans le titre, la description et le texte

6.3 Maillage interne
   - Lie tes pages entre elles avec des liens contextuels
   - Aide Google à comprendre l'architecture de ton site

6.4 Backlinks
   - Obtenir des liens depuis d'autres sites = signal fort pour Google
   - Inscris ton site dans des annuaires, publie des articles invités, etc.

6.5 Données structurées (Schema.org)
   - Enrichit les résultats Google (étoiles, dates, etc.)
   - Exemple pour un article :

   <script type="application/ld+json">
   {
     "@context": "https://schema.org",
     "@type": "Article",
     "headline": "Mon article SEO",
     "author": { "@type": "Person", "name": "Jean Dupont" },
     "datePublished": "2025-01-15"
   }
   </script>

────────────────────────────────────────────────────────────────────────────────
ÉTAPE 7 — WORKFLOW GITHUB + VERCEL POUR LE SEO
────────────────────────────────────────────────────────────────────────────────

7.1 Déploiement automatique
   - Chaque push sur la branche main → déploiement auto sur Vercel
   - Les Pull Requests créent des previews (URLs en *.vercel.app)
   - Attention : les previews Vercel sont indexables par défaut !
     → Ajoute X-Robots-Tag: noindex sur les previews :

   Dans vercel.json :
   {
     "headers": [
       {
         "source": "/(.*)",
         "has": [{ "type": "host", "value": "(?!monsite\\.com).*\\.vercel\\.app" }],
         "headers": [{ "key": "X-Robots-Tag", "value": "noindex" }]
       }
     ]
   }

7.2 Variables d'environnement
   - Stocke l'URL de production dans Vercel > Settings > Environment Variables
   - Ex : NEXT_PUBLIC_SITE_URL=https://monsite.com
   - Utilise-la dans ton code pour générer les URLs canoniques dynamiquement

7.3 Checklist avant chaque déploiement (à mettre dans ton README ou CI)
   [ ] Les balises <title> et <meta description> sont renseignées
   [ ] L'URL canonique est correcte
   [ ] Les images ont un attribut alt
   [ ] Le sitemap est à jour
   [ ] Pas de liens cassés (outil : broken-link-checker)
